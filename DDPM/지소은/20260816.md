# Denoising Diffusion Probabilistic Model   
# 논문의 의의   
이 논문을 통해 **확산 모델로도 고품질 샘플 생성이 가능함**을 최초로 증명   

# 배경   
# 배경1    
[확산 모델](hwagsan-model.md) : 가짜 노이즈에서 진짜 데이터를 만들어내는 연속된 파이프라인([마르코프 체인](mareukopeu-cein.md))   
- 체인의 전이하면서 확산 과정을 역전시키도록 학습   
- 확산 과정: 데이터 생성(샘플링)을 하려면, 역설적으로 원본 데이터를 완전히 망가뜨리는 작업(확산 과정)부터 선행되어야 한다.(계속해서 노이즈를 부어서 원본을 알아볼 수 없도록 더해가는 과정)   
- 가우시안 노이즈는 여러 번 중첩해서 더해도 공식 적용하기 좋다. 그래서 컴퓨터가 과부하가 걸리지 않도록 소량씩 쪼개서 넣는다.   
- 샘플링 체인의 전이 - 조건부 가우시안으로 설정하는 걸로 충분함( ⇒ 간단한 신경망 매개변수화가 가능하게 함.   
- 인공지능이 노이즈를 걷어낼 때 어려운 계산 없이 **가우시안의 평균과 분산**만 신경망이 예측하게 하면 충분함.(노이즈 더할 때 조금씩만 더했기 때문에 빼낼 때도 미세한 덩어리만 덜어내면 됨.)   
- 이 논문의 방법론은 완전히 뜬금없는 새로운 것이 아니라, 이미 학계에서 검증된 강력한 이론들과 수학적으로 완벽히 연결됨을 증명함.   
 --- 
   
# 배경2   
## 역과정(Reverse Process) - 인공지능이 이미지를 '생성'하는 과정   
$pθ(x0):=∫pθ(x0:T)dx1:T$   
1. 모델이 최종적으로 만들어낸 완벽한 가짜 데이터가 나올 확률 구하는 공식   
   
> $(x_1  … x_T)$ : $(x_1 … x_T)$ 와 동일한 차원의 잠재변수    
> : 예를 들어, 원본 이미지가 256X256 해상도라면, 1~1000번째 노이즈 모두 똑같은 256X256 크기의 픽셀 덩어리다.   

   
2. $(p\_\theta(x\_{0:T}))$ : 역과정(결합 분포)   
> 생성의 출발점은 완전한 백색소음 화면이다. 여기서부터 시작해서, 인공지능은 훈련받은 대로 노이즈를 아주 조금씩 깎아나가는 파이프라인이다.   

$p\_\theta(x\_{0:T}) := p(x\_T) \prod\_{t=1}^T p\_\theta(x\_{t-1}\|x\_t), \quad p\_\theta(x\_{t-1}\|x\_t) := \mathcal{N}(x\_{t-1}; \mu\_\theta(x\_t, t), \Sigma\_\theta(x\_t, t))$   
-생성 과정 수학식(백색소음($p(xT)$)에 현재 노이즈($x\_t$)를 보고 직전 상태($x\_{t-1}$)로 한 겹 벗겨내기)-   
 --- 
## 순방향 과정(Forward Process) - 원본을 일부러 망가뜨리는 과정   
$q(x\_{1:T}\|x\_0) := \prod\_{t=1}^T q(x\_t\|x\_{t-1}), \quad q(x\_t\|x\_{t-1}) := \mathcal{N}(x\_t; \sqrt{1 - \beta\_t}x\_{t-1}, \beta\_t I)$   
1. 다른 AI 모델들은 데이터를 어떻게 망가뜨릴지를 인공지능이 고민했다.   
   
2. 위 공식은 '한 단계 망가뜨리는 공식'이다.    
 --- 
## 학습 방법 및 최적화   
$\frac{일반적인 변분 경계}{음의 로그 가능도}$ → 최적화하여 수행   
1. 원래 AI 훈련은 '오차 구하고 최소화 하기' 이다. 하지만 이 오차 계산은 수학적으로 불가능하다.   
2. 직접 계산 대신, '이 값보다는 무조건 작다'는 변분 경계를 구해서 상한선을 낮춘다.   
   
   
$bb{E}q [-\log p\theta(x\_0)] \leq \mathbb{E}q \left[ -\log \frac{p\theta(x\_{0:T})}{q(x\_{1:T}\|x\_0)} \right] = \mathbb{E}q \left[ -\log p(x\_T) - \sum{t \geq 1} \log \frac{p\_\theta(x\_{t-1}\|x\_t)}{q(x\_t\|x\_{t-1})} \right] =: L$   
-오차 상한선($L$) 구하는 공식(AI가 빼는 노이즈($p$)와 붓는 노이즈($q$) 사이의 차이를 나타냄)-   
 --- 
## 기타 사항   
- 순방향 과정의 분산 $B\_t$ : 재매개변수화를 통해 학습 or [하이퍼파라미터](haipeoparamiteo.md)로 고정   
   
> 노이즈를 얼마나 부을지 딥러닝이 스스로 학습하게 할 수 있지만, 귀찮기 때문에 사람이 상수로 고정해 버려도 성능이 꽤 잘 나온다.   

   
- 역과정의 표현력: $P\_0(x\_{t-1}\|x\_t)$ 에서 가우시안 조건부 분포를 선택(부분적으로 보장)   
   
> 노이즈를 빼는 역과정이 수학적으로 붕괴하지 않고 안정적으로 작동하려면, 한 번에 붓는 것이 아니라 아주 작게 쪼게서 부어야 한다는 필수조건   

   
- **(중요)임의의 타임스템 $t$에서 $x\_t$를 닫힌 형식으로 샘플링할 수 있다**   
   
> 100번째 노이즈 이미지를 만들 때 1번부터 하나하나 계산하며 올라갈 필요 없이, 원본 이미지 $x_0$에서 한 번의 공식 대입으로 만들 수 있다.   

$q(x\_t\|x\_0) = \mathcal{N}(x\_t; \sqrt{\bar{\alpha}\_t}x\_0, (1 - \bar{\alpha}\_t)I)$   
$\alpha\_t := 1 - \beta\_t$ 또는 $\bar{\alpha}t := \prod{s=1}^t \alpha\_s$ 표기법 사용   
   
- 확률적 경사 하강법을 사용하여 $L$의 무작위 항들을 최적화함으로써 효율적인 학습 가능   
   
$\mathbb{E}q \left[ \underbrace{D{KL}(q(x\_T \|x\_0) \parallel p(x\_T ))}{L\_T} + \sum{t>1} \underbrace{D\_{KL}(q(x\_{t-1}\|x\_t, x\_0) \parallel p\_\theta (x\_{t-1}\|x\_t))}{L{t-1}} - \underbrace{\log p\_\theta (x\_0\|x\_1)}\_{L\_0} \right] (5)$   
> 아까 상한선 공식($L$)은 그대로 쓰면 분산이 크면서 불안정해진다.(컴퓨터 버벅거림)   
> 그래서, $D_{KL}$이라는 '분포 간의 거리를 재는 공식을 도입하여, 식을 세 덩어리($L_T$, $L_{t-1}$, $L_0$)로 재조립   
> → 컴퓨터 속도 향상, 안정적   

이어서,,   
$q(x\_{t−1}∣x\_t,x\_0)=N(x\_{t−1};μt(x\_t,x\_0),β\_{tI})$   
-정답지를 수학적으로 정의한 공식-   
  - $\tilde{\mu}t(x\_t, x\_0) := \frac{\sqrt{\bar{\alpha}\_{t-1}}\beta\_t}{1 - \bar{\alpha}t}x\_0 + \frac{\sqrt{\alpha\_t}(1 - \bar{\alpha}\_{t-1})}{1 - \bar{\alpha}\_t}x\_t$ :    
  - $\tilde{\beta}t := \frac{1 - \bar{\alpha}\_{t-1}}{1 - \bar{\alpha}\_t}\beta\_t$   
> 몬테카를로 추정치 대신, Rao-Blackwellized 방식으로 닫힌 형식 표현식(무한대 계산, 시뮬레이션 과정X, 사칙연산 같이 기호들로 깔끔하게 딱 떨어지는 수학 공식)을 사용했다.
